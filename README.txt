リヴリー HPwr調整ツール
=====================

使い方
1. ゲーム内の現在のHPwr（0〜480の整数）を入力します。
2. HPwrを確認した時刻を合わせます。「今の時刻に更新」で端末の時刻を使えます。
3. 「今すぐ」か「時刻を指定」を選びます。指定できるのは同じ日の23:59までです。
4. おすすめの回数、24時の残量、上限により失う回復量を確認します。

計算仕様
- 上限480、1分に1回復、水やり1回10消費。
- 指定時刻までの回復にも480の上限を適用。
- 指定時刻にまとめて水やりする前提で、24時に480を確保できる最大回数を計算。
  24時までの回復が足りない場合は0回を推奨し、届く残量を表示。
- 残量で実行できる回数までに制限。1〜9の端数は無理に消費しません。
- 水やり前と水やり後の回復の無駄を別々に表示。
- 秒数、水やり中の経過時間、他のHPwr消費、日付をまたぐ予約は対象外。
- 「今すぐ」も入力した確認時刻が基準です。時刻やHPwrは自動で進めません。
  アプリを開いたまま日付が変わったときは、更新を促す案内を表示します。

起動・テスト（外部パッケージのインストール不要）
- ファイルを直接開く: index.html をブラウザで開けば計算機能を使えます。
- Node.js 18以上: npm start → http://127.0.0.1:8000
- Pythonがある場合: python -m http.server 8000 --bind 127.0.0.1
- 計算・PWA構成テスト: npm test（Node.js標準のtest runnerを使用）

スマホにインストール
- このフォルダの公開用ファイルをHTTPS対応の静的サーバーに配置します。
  index.html / styles.css / calculator.js / app.js / sw.js /
  manifest.webmanifest / icon.svg / icons/ のすべてが必要です。
- Android: 対応ブラウザでは画面内のインストールボタン、またはブラウザのメニュー。
- iPhone/iPad: Safariの共有メニュー → ホーム画面に追加。
- file:// やスマホからアクセスするHTTPのLANアドレスではPWAは使えません。
  localhost/127.0.0.1は、そのブラウザを動かしている端末自身だけを指します。
- 初回のオンライン読み込み後、「準備完了」が表示されればオフラインでも計算できます。
- 新版が見つかると更新ボタンを表示します。更新時に入力内容はリセットされます。
- 公開ファイルを変更したら、sw.js の VERSION も更新してください。

構成
- calculator.js: DOM・現在時刻に依存しない計算と入力検証（ブラウザ/Node共用）
- app.js / styles.css / index.html: 入力・結果表示、スマホ対応、インストール案内
- sw.js: スコープ別キャッシュ、オフライン対応、ユーザー操作による新版への更新
- icons/: 192/512pxのPNGとApple用180pxアイコン
- tests/: 境界値、独立したシミュレーションとの比較、PWAキャッシュの検証
- scripts/serve.cjs: localhost限定の確認用静的サーバー

調査時に修正した点
- 「消費できる最小回数」という説明を「480を確保できる最大回数」に訂正。
- 空欄・範囲外・小数・不正時刻・過去の予定時刻を検証。
- 24時ちょうどの満タン時刻は「24:00」、翌日なら「翌日 HH:mm」と表示。
- Service Workerが同じ配信元の他アプリのキャッシュを削除・参照しないよう修正。
- SVGだけだったアイコンに、インストール用PNGとApple用アイコンを追加。
